# exES

ErogameScape の作品ページに通販サイトの価格と過去のキャンペーンを表示する Chrome 拡張です。
Manifest V3 に対応しています。

## ビルド

Node.js 22 以降で実行してください。

```sh
npm ci
npm run check
npm test
npm run build
```

`dist` に拡張機能一式が出力されます。開発中は `npm run dev` で変更を監視できます。
開発・本番ともに、Manifest V3 の CSP で禁止される eval を使わないバンドルを生成します。

## Chrome での読み込み

1. `chrome://extensions` を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で `dist` を選択します。
3. ErogameScape の作品ページを再読み込みします。

更新時は拡張機能の「更新」ボタンを押し、作品ページも再読み込みしてください。
ストア版とローカル版を同時に有効にすると表示が重複するため、検証時は片方だけ有効にします。

## Manifest V3 への移行内容

- バックグラウンドを Service Worker に変更し、接続先を `host_permissions` に移動。
- Axios / XMLHttpRequest を `fetch` に置き換え、日本語文字コードの自動判定を維持。実サイトの応答を待てるようタイムアウトを 15 秒に変更。
- 外部通信は Service Worker に集約されているため、CORS ヘッダーを書き換える宣言的ネットワークルールと権限を削除。
- メッセージ通信の失敗を呼び出し元に伝え、ページの load 後にスクリプトが挿入された場合にも初期化。
- DLsite の価格取得 URL で商品 ID にキャッシュ指定が混ざっていたクエリ区切りを修正。

## 価格取得の修正（1.1.1）

- 駿河屋の「￥4,080 ～ ￥6,600」を `4,080～6,600円` と表示。数字の連結を防ぎ、通常品・マケプレを区別し、欠品・ディスク単品を通常品の最安値に混ぜません。
- Getchu の現行商品 URL・税込価格欄・JAN コードに対応。
- ソフマップの動的商品一覧を取得し、新品・中古・「○円～」を区別。
- Amazon の現行価格欄に対応し、参考価格や関連商品の価格を除外。
- DLsite のアフィリエイト URL と商品 ID に対応し、セール価格・0 円を保持。
- FANZA の現行ダウンロードページ・セール価格・従来の通販ページに対応。ポイント・値引額・参考価格を販売価格と誤認しません。
- 過去キャンペーンは列名から読み取り、新しい順で表示。取得失敗と該当なしを区別。
- 一店舗の取得に失敗しても他の店舗の価格を表示し、失敗した店舗への確認リンクを残します。

FANZA・ソフマップの年齢確認、駿河屋のセーフサーチで商品が非表示の場合は案内を表示します。
同じ Chrome プロファイルで各サイトを開き、サイトの確認・設定を終えてから批評空間を再読み込みしてください。
拡張はその 3 サイトの既存セッションを通信に使用します。年齢確認を自動承認したり、Cookie を読み出して保存したりはしません。

参考: [Chrome の移行ガイド](https://developer.chrome.com/docs/extensions/develop/migrate/to-service-workers)、
[拡張機能からの外部通信](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)。

## 動作確認

`npm test` は通信・文字コード・エラー処理に加え、実応答から必要部分を抽出した HTML/JSON で
6 サイトの価格解析・リンク・キャンペーン・店舗単位の失敗を検証します。

2026-11-07 に Chromium 149 で実際の批評空間の 3 作品を開き、価格・リンク・過去キャンペーンを確認しました。
Service Worker の停止を確認した後、ページ再読み込みによる再起動・価格再取得も成功しました。
Amazon は実商品への通信と表示を、Amazon リンクを置いた検証ページで確認しています。
確認した作品・価格・条件は [実サイト検証記録](docs/live-verification.md) を参照してください。

価格は取得時点の販売価格で、送料・ポイント還元を含みません。すべての商品の網羅確認はしていません。
通販サイトの HTML 変更やアクセス制限により取得できない場合は、表示したリンクからサイトで確認してください。
